## Files

## Deploy via CMD

```cmd
cd frontend
git init
git add .
git commit -m "Initial frontend commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/nasdaq-analysis-frontend.git
git push -u origin main
